# gitmirror

Переносит коммит-активность из приватных репозиториев (GitLab, Bitbucket,
самохостед) в репозиторий-зеркало на GitHub, чтобы работа вне GitHub
отражалась в графике вкладов.

В зеркало попадают только пустые коммиты с датами авторства оригиналов:
ни кода, ни оригинальных сообщений.

Статус: в разработке.
